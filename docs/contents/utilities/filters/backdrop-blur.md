---
title: Backdrop Blur
description: Utilities for blurring what is behind an element.
---
The element needs a background that lets what is behind it show through, such as a translucent surface. The class for the default 8px is `.backdrop-blur-blur`; there is no bare `.backdrop-blur`.

<div>
    <table-utility prefix="backdrop-blur" property="blur" attribute="backdrop-filter"></table-utility>
</div>
