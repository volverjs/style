---
title: Skeleton
description: Skeleton is a placeholder that stands in for content still loading.
---

A `vv-skeleton` stacks `vv-skeleton__item` bars, each one line tall; size them with the width utilities. `--skeleton-background` and `--skeleton-shine-color`, set on the block, recolor the bars and the shine that runs across them. Mark the region that is loading with `aria-busy="true"`.
