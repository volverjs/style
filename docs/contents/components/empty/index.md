---
title: Empty
description: Empty is what a list, a table or a page shows in place of its content, with an optional way out.
isNew: true
---

The block centers a `media`, a `title`, a `description` and the `actions`, each optional. The message stays quiet on purpose: no color of state, only the title in the strongest text color. The icon inside `vv-empty__media` takes its size from the font size, so an icon of `1em` fits as it is.

<code-editor resource-folder="empty" resource-name="default" class="mb-lg"></code-editor>

### Compact
Add `vv-empty--compact` inside a list, a table or a card, where the frame is already there and a page sized empty state would push the rest away.

<code-editor resource-folder="empty" resource-name="compact" class="mb-lg"></code-editor>

### Bordered
Add `vv-empty--bordered` for an area waiting to be filled, such as a drop zone.
