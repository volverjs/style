---
title: Card
description: Card is a flexible container for a header, content, a picture and a footer.
uiVue: true
---

A `vv-card` takes a `header`, a `vv-card__content`, a `picture > img` (or an `img.vv-card__picture`) and a `footer`, each optional: the header and the footer are styled as plain tags. `vv-card--glass` makes the card translucent and blurs what is behind it, for a card over an image.
